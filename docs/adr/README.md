# Architecture decisions

1. **Source tables stay separate.** WPP exposure reconstructs the UN's own modeled rates. WHO registration counts follow reporting coverage and its population file contains midyear heads. Combining them would create a rate with no coherent denominator. The two staging paths retain separate provenance, comparisons, and data permissions.
2. **Bind input to release bytes.** A URL can serve a revised file under the same name. The acquisition boundary pins SHA-256 and validates size before atomically publishing a file. A new release requires a new receipt and an explicit migration. This adds acquisition work and makes repetition auditable.
3. **Retain original age resolution.** Grouping raw death rates by arithmetic mean erases exposure weights and can skew expectancy. Store complete cells, sum deaths and person-years into each declared forecast age interval, and derive the rate afterwards. Comparisons at 100+ can still identify rounding-related holes.
4. **Use Arrow and Parquet at the storage boundary.** A persistent server database would simplify concurrent remote access and add an operational dependency. Sorted Parquet exposes typed, immutable files, with DuckDB predicate pushdown for interactive filters and Arrow transfer to the model cube. This favors local reproducibility over remote writes.
5. **Separate probability assumptions.** Constant force gives exact analytic checks, stable probabilities for extreme rates, and easy path propagation. Fixed a(x) enables a published method comparison but can imply an impossible probability for unsupported schedules. Reject that case rather than altering the supplied age assumption.
6. **Put period arithmetic in a bounded Rust kernel.** Shared C ABI calls keep the numerical core reusable and small. Python retains ownership of all buffers and converts only checked output into typed rows. This limits native state and sacrifices a zero-copy Python result format.
7. **Treat cohort extraction as a diagonal.** Period age cells include pieces of two birth cohorts. The program records exact age and year indexing and labels the diagonal approximation. Projected rates can complete a conditional path only with explicit tail support.
8. **Use equal-population loss weighting.** Weighting directly by total counts would concentrate training on the largest populations. Within each population retain the count offset, then normalize by total deaths before averaging across strata. This sacrifices the literal pooled count likelihood in favor of a defined cross-population objective.
9. **Make time extrapolation part of the model.** An MLP fitted on time features can behave arbitrarily beyond the training range. The structured model holds nonlinear effects at the origin and continues a fitted trend. The alternative rolls a learned latent transition forward without adding held-out innovations. Compare both against predeclared time-series baselines.
10. **Retain unknown causes as explicit partitions.** Redistributing ill-defined or unmatched counts would make coding shifts look like disease shifts. The partition retains both and gives neither a scenario multiplier. A national tabulation without verified matching population can still support a conditional composition comparison.
11. **Store all study outcomes and replay checkpoints.** Aggregates cannot show exactly which forecasts changed under a split or a new fit. Each result contains age rates, draws, denominator support and per-stratum outcome. Replays add verification cost but reveal divergence when ordinary checksums have been recomputed.
12. **Serve a local frozen atlas.** Runtime retraining would blur model identity and permit unbounded work. Startup loads one checkpoint, runs bounded forecasts, and builds uncertainty paths. The service can answer without a checkpoint using its historical panel. New models enter through a distinct training command and service restart.
13. **Use an explicit acceptance candidate.** Technical measurements and open research requirements coexist. Candidate verification checks emitted artifacts and numerical relations, while full verification exits nonzero if any mandatory gate remains open. Separating the commands keeps diagnostic outputs reviewable.
