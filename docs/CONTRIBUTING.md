# Contributing

Use the locked dependency environment and the default CPU path. Keep units and provenance in typed records before adding model inputs. Run focused tests and the seeded demo for changes in the normal command path. A source or protocol change that can affect results requires new evidence.

Describe boundary conditions and numerical decisions close to the implementation. Use explicit exclusion reasons and preserve failing examples. Include actual measured results when changing a performance claim. Keep restricted archives, optimizer state, browser traces, and local research ledgers outside Git. The [data source register](DATA.md) contains attribution and permissions.

The numerical libraries provide tensor and optimizer primitives. The scientific kernels and models belong to this repository. Dependency licenses are summarized in [third-party provenance](THIRD_PARTY.md).
